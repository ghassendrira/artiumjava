# ArtiumJava – Application Desktop JavaFX pour Gestion Artistique 🎨

ArtiumJava est une application **JavaFX** connectée à **MySQL** permettant la gestion complète d'un centre artistique.

## 🧩 Modules disponibles
- Gestion des utilisateurs (avec rôles)
- Cours et progression des participants
- Quiz interactifs
- Forum local
- Événements (inscription/annulation)
- Boutique (ajout/achat de produits)
- Impression, recherche en direct, filtrage

## ⚙️ Technologies
- Java 17 / JavaFX
- Scene Builder (FXML + CSS)
- JDBC / MySQL
- Architecture MVC
- Librairie de gestion PDF/Print (facultatif)

## 🧪 Lancer l'application
1. Ouvrir avec IntelliJ IDEA ou autre IDE Java
2. Configurer la base de données dans `MyDatabase.java`
3. Lancer `MainFX.java`
